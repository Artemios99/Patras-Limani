# PATRAS LIMANI

## Port Management System

Το “PATRAS LIMANI” είναι ένα πληροφοριακό σύστημα διαχείρισης λιμανιού, το οποίο αναπτύχθηκε στο πλαίσιο του μαθήματος Τεχνολογία Λογισμικού.

Στόχος του συστήματος είναι η οργάνωση και αυτοματοποίηση των βασικών λειτουργιών του λιμανιού της Πάτρας, όπως:
- διαχείριση πλοίων,
- αιτήματα εισόδου στο λιμάνι,
- αιτήματα πρόσδεσης,
- διαχείριση docks,
- παρακολούθηση κατάστασης πλοίων,
- και διαχείριση πληρωμών.

# Ρόλοι Χρηστών

Το σύστημα υποστηρίζει 4 διαφορετικούς ρόλους χρηστών:

## Captain
Ο καπετάνιος μπορεί να:
- Καταχωρεί πλοίο
- Υποβάλλει αίτημα εισόδου στο λιμάνι
- Υποβάλλει αίτημα πρόσδεσης
- Παρακολουθεί την κατάσταση των πλοίων

## Ship Owner
Ο ιδιοκτήτης πλοίου μπορεί να:
- Προβάλλει τα πλοία του
- Βλέπει και να πληρώνει χρεώσεις

## Dock Worker
Ο λιμενεργάτης μπορεί να:
- Βλέπει αναθέσεις docks
- Ενημερώνει την κατάσταση docking
- Αποδεσμεύει docks

## Port Authority Manager
Ο λιμενάρχης μπορεί να:
- Διαχειρίζεται αιτήματα
- Εγκρίνει ή απορρίπτει αιτήματα
- Αναθέτει θέσεις docking
- Παρακολουθεί την κατάσταση docks
- Βλέπει πρόγραμμα αφίξεων
- Παρακολουθεί πληρωμές
